💻 Menjalankan di Laptop (Chrome)

1Buka PowerShell

Buka PowerShell di folder project ini

2Jalankan Script

.\run_web.ps1

Atau manual:

flutter run -d chrome
PENTING: Yang benar adalah flutter run -d chrome (TANPA spasi antara - dan d)
❌ SALAH: flutter run - d chrome
✅ BENAR: flutter run -d chrome

📱 Menjalankan di HP Android

1Persiapan HP (Sekali Saja)

  • Aktifkan Developer Options:
    • Buka Settings → About Phone
    • Tap "Build Number" 7 kali
  • Nyalakan USB Debugging:
    • Settings → Developer Options
    • Aktifkan "USB Debugging"

2Sambungkan HP ke Laptop

  • Gunakan kabel USB
  • Pilih mode "File Transfer" di HP
  • Izinkan USB Debugging saat popup muncul

3Jalankan Script

.\run_android.ps1

Script ini akan otomatis:

Cek device yang tersedia
Fix error "device offline" (restart ADB)
Install & jalankan app di HP

🔧 Fix Error "device offline"

Script run_android.ps1 sudah otomatis menangani error ini!

Jika masih error, coba manual:

adb kill-server
adb start-server
flutter run

Solusi Lain:

  • Cabut & pasang ulang kabel USB
  • Matikan & nyalakan ulang USB Debugging
  • Ganti kabel USB (gunakan yang original)
  • Coba port USB lain di laptop
  • Restart HP dan laptop

📦 Membuat APK (Install Tanpa Kabel)

Untuk install di HP tanpa kabel USB:

flutter build apk --release

File APK akan tersimpan di:

build\app\outputs\flutter-apk\app-release.apk

Transfer ke HP via WhatsApp/Drive/Email, lalu install.
